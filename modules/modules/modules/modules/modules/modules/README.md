# Oil Refining Calculator with AI Chat

A Gradio web app that:
- Fetches live crude oil prices.
- Calculates yields of refined products based on barrel input.
- Shows total market value minus refining fees.
- Saves calculation history.
- Includes an AI chat assistant powered by DeepSeek.
